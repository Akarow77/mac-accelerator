# 연구 요약 — 2026-09-29

[English](RESEARCH_SUMMARY.md) · [한국어](RESEARCH_SUMMARY.ko.md) · [프로젝트](../README.ko.md)

## 범위

Mac Accelerator는 M2 MacBook Air + comma 3X 실험에서 분리한 독립형
Apple Silicon / Core ML 벤치마크 앱·서버입니다. comma/sunnypilot 공식 제품,
네이티브 eGPU 드라이버, 실차용 제어 시스템이 아닙니다. 모델과 기기 펌웨어는
이 저장소에서 배포하지 않습니다.

## 구현된 기능

- 독립 앱 패키징, 설정과 인증 식별자.
- 인증·크기 제한이 있는 전송과 맥 측 관찰 전용 재생.
- 선택적 NV12 전처리 비교 및 차량 분리 기기용 시간 제한 벤치 도구.
- 실험용 전송 서버의 요청별 기한 초기화 수정.
- 실험용 scatter/gather 프레이밍 검사. 운영 상한은 4MiB이며 8MiB는
  명시적 벤치 옵션으로만 시험했습니다.

앱에는 실시간 3X 카메라 연결, 기기 파라미터 쓰기, 차량 제어 출력 기능이
없습니다. GPU/ANE 분할 실험과 시간 문맥 링 버퍼는 추론 서버에 통합하지 않았습니다.

## 알려진 전원 안정성 문제

차량 + 맥 직접 USB 연결 구성에서 기기 전체 재부팅이 발생했고, sunnypilot
master 복원 후에도 관찰됐습니다. 운용 관찰에서는 맥 분리 후와 차량 분리
환경에서 재부팅이 보고되지 않았습니다. 부하·관찰 시간을 맞춘 A/B 시험은
아닙니다. 부팅 로그에 UVLO/SMPL 표시가 있지만 역류·고장 부품·전원 선택을
특정하는 증거는 아닙니다.

USB 입력 표본에는 약 4.39V / 1.35A, 다음 부팅에는 약 4.84V / 1.30A가
기록됐습니다. PD는 5V·상한 3A였습니다. 드라이버 표본이며 재부팅 순간 파형이나
맥 단자 실측이 아닙니다. 보존된 패닉의 FIFO 호출 경로는 GLINK 내부 IPC 소스와
일치하며 USB·카메라 경로로 단정할 수 없습니다. 전원 사건과의 관계는 미확정입니다.

검증된 전기적 해결책이나 데이터 전용 전원 설정은 없습니다. 차량에서 맥 직접
USB 사용은 중단 상태입니다. [전원 상태와 근거 소스](POWER_STABILITY_STATUS.md)

## Upstream 구조 분석 결과

확인한 Chestnut은 GPU warp 전에 NV12 이미지 범위를 전송합니다. 미리 줄인
모델 텐서도, 전체 카메라 할당 영역도 아닙니다. 조사한 1928×1208 배치에서
NV12 범위는 이미지당 3,735,552바이트, 스냅샷 할당은 4,804,608바이트였습니다.
22.25% 차이는 크기 계산이지 구현된 속도 향상이 아닙니다. 두 이미지를 20Hz로
전송하려면 오버헤드 전 약 1.195Gbps가 필요합니다.
[고정 소스 분석과 대역폭 계산](USB_POWER_ISOLATION_RESEARCH_2026-09-29.md)

## 검증 상태

지속적인 보정 카메라 수신, 시간 문맥 정확성, 로컬 모델 공존, 단절·오래된
결과 처리, 열을 포함한 장시간 지연은 미검증입니다. M1과 다른 M칩도 시험하지
않았습니다. 이 결과는 실차 제어를 승인하지 않습니다. 원본 로그·식별자·주소·
인증 정보·모델·카메라 이미지는 공개 보고서에서 제외합니다.
